Maqiri 対応形式と制限（FORMAT_LIMITS）
=====================================

入力（1 本の動画ファイル）
- コンテナ: MP4 / MOV（拡張子だけでなく中身で判定します。MKV / WebM / AVI は非対応）
- 映像: H.264 または HEVC(H.265)、8bit、SDR、プログレッシブ、映像トラック 1 本
  - 非対応: HDR(PQ / HLG)、Dolby Vision、インターレース、10bit 以上、VP9 / AV1 等、暗号化、破損ファイル
- 解像度: 回転後の長辺 1920 / 短辺 1080 以内（例: 1920×1080、1080×1920、1280×720）。4K は非対応
- フレームレート: 25 / 29.97 / 30 / 50 / 59.94 / 60fps、および可変フレームレート（VFR）の一般的な録画
- 長さ・容量: 30 分以内、4GiB 以内。長さが 0 秒 / 不正なものは拒否
- 音声: AAC または PCM、モノラルまたはステレオ（6ch 等は非対応）。音声なしは E_NO_AUDIO
  - 複数の音声トラックがある場合は 1 本を選びます。選んだトラックだけを出力し、その他は出力に含まれません
  - 音声が映像より短い場合は末尾を無音で埋めます。音声の開始ずれは映像の最初のフレームを基準に揃えます
- 入力できないもの: URL、プレイリスト、フォルダー、ネットワーク上のパス（ローカルに保存してから選んでください）

出力
- H.264 / AAC の MP4（faststart）、30fps 固定（25fps 入力も 30fps に変換）、48kHz
- 画質: 1080p30（目標 12Mbps）または 720p30（目標 6Mbps）。縦横比を維持し、拡大はしません
- 音声: 選択トラックのチャンネル数を維持。AAC 192kbps（ステレオ）/ 128kbps（モノラル）
- 色: SDR BT.709 に統一。色情報が無い入力は「SDR BT.709 として処理」し、色の再現は保証しません
- 保存先: PC 内のドライブ。ネットワークドライブは非対応。元の動画と同じファイルには保存できません
- 空き容量: 予想出力サイズ ×1.5 + キャッシュ + 1GiB を開始前に確認します

判定の仕組みと限界
- 20ms ごとの音量（RMS、チャンネル別の最大）が閾値未満の区間を「無音」とみなし、既定 0.8 秒以上続く区間を候補にします
- 声の前後に既定 0.15 秒ずつの余白を残します。削除は 30fps のフレーム単位で、内側へ丸めます（削りすぎない）
- 常時 BGM や大きな環境音がある動画では無音を検出できないことがあります。BGM 分離や高度な音声区間検出は行いません
- 語尾の小声が候補に含まれることがあります。つなぎ目を聞いて「この間を残す」で戻してください。「声を絶対に切らない」ことは保証しません
- 候補が 600 件を超える場合は理由付きで停止します（超過分を黙って捨てません）

エラーコードと対処
- E_FORMAT: 対応形式を確認し、動画を選び直してください
- E_NO_AUDIO: 音声付きの動画を選んでください
- E_TOO_LONG / E_TOO_LARGE / E_TOO_BIG_FRAME: 30 分 / 4GiB / 1080p 相当以内の動画を選んでください
- E_ENCODER: この PC の H.264 エンコーダー（Windows Media Foundation）が使えません。Windows Update の適用後に再試行してください
- E_ENCODE: 書き出しに失敗しました。再試行するか 720p を選び、繰り返す場合は診断ログを保存してください
- E_SYNC: 完成物の検証に失敗したため保存しませんでした。元の動画は変更されていません
- E_SPACE: 保存先の空き容量が不足しています。保存先を変更してください
- E_NETWORK_DRIVE / E_SAME_PATH: PC 内の別のファイル名に保存してください
- E_HASH_MISMATCH: プロジェクトの元動画と内容が一致しません。同じ動画ファイルを選び直してください

体験版（デモ）
- 入力の先頭 90 秒だけを解析・書き出しします。制限はアプリ本体（main プロセス）で強制されます
