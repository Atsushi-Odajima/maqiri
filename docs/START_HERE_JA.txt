Maqiri（マキリ）— はじめにお読みください
==========================================

Maqiri は、1 人で話す動画（講座、解説、商品紹介）の「話していない長い間」を見つけて詰め、
確認してから MP4 に保存する Windows 11（x64）向けアプリです。

できること
- 動画を選ぶ → 「自然に」などの間隔を選ぶ → つなぎ目を聞く → 必要な間を残す → 保存。
- 元の動画は書き換えません。別名の MP4 を作ります。
- 保存したプロジェクト（.maqiri.json）で、あとから編集し直せます。カット範囲の CSV/JSON も書き出せます。

できないこと
- 字幕・文字起こし・「えー」「あのー」の削除・話の意味の理解・BGM 追加・テロップはできません。
- BGM が常に鳴っている動画、大きな環境音、極端な小声では無音を見つけられないことがあります。

インストール
1. Maqiri-Demo-Setup-x64.exe（体験版）または Maqiri-Full-Setup-x64.exe（製品版）を実行します。
   管理者権限は不要です（ユーザーごとのインストール）。
2. SmartScreen の警告が出る場合があります（署名の状態は RELEASE_CHECKLIST / CHANGELOG を参照）。
   「詳細情報」→「実行」で続行してください。Windows Defender を無効化する必要はありません。
3. インストール後、スタートメニューの「Maqiri」から起動します。インターネット接続は不要です。

体験版（デモ）の制限
- 入力の先頭 90 秒だけを解析・書き出しします。透かしはありません。
- 製品版では 30 分 / 4GiB 以内の動画を全体処理できます。

対応形式の要点（詳細は FORMAT_LIMITS.txt）
- MP4 / MOV、H.264 または HEVC（8bit SDR、プログレッシブ）、AAC / PCM（モノラル / ステレオ）
- 30 分 / 4GiB / 1080p 相当（縦 1080×1920 可）以内、25〜60fps（可変フレームレート可）
- 出力: H.264 / AAC の MP4、30fps、最大 1080p

同梱ファイル
- Maqiri-*-Setup-x64.exe … インストーラー
- SHA256SUMS.txt … インストーラーのハッシュ
- START_HERE_JA.txt（本書）/ FORMAT_LIMITS.txt / EULA_DRAFT.txt / THIRD_PARTY_NOTICES.txt / CHANGELOG.txt
- インストール先の resources/media-tools/ … FFmpeg（LGPL v3）の実行ファイルと対応ソース、ライセンス

アンインストール
- Windows の「アプリと機能」から Maqiri を削除します。プロジェクトファイルと元の動画は削除されません。
