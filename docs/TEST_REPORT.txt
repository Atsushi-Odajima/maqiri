3. 統合テスト（npm run test:media、実 ffmpeg/ffprobe を spawn）: 合格 49/49（3 ファイル、約 75 秒）
fixture: scripts/generate-fixtures.mjs が lavfi で 30 本を自動生成（色面 + 白フレームマーカー、ノイズ発話 + 1kHz ビープ + 既知無音。権利問題なし）
B 音声
- 左だけ発話/右無音、左右逆相: チャンネル別 RMS の最大で quiet 誤判定なし（単純平均なら逆相は消える）
- 極小声 -42dBFS: -35 で quiet、-45 で有声として残る
- 一定 BGM -30dBFS: -35 では無音を検出できない（文書化した限界）、-25 なら検出
- 咳（100ms, -15dBFS）: run が 2 つに分かれる
- 全無音 → all-quiet、全有声 → no-candidates
- 選択トラック違い: 無音の default トラックは all-quiet、声のトラックでは候補あり（UI で選択必須）
- 解析の 0 点 = 映像の 0 点: 音声 +200ms 遅延で無音境界が 200ms 後ろへ、音声先行 150ms で 150ms 前へ（±40ms = 2 窓以内）
- 短い音声: 末尾を無音でパディング、窓数 = ceil(N·1600/960)
- DEMO limitFrames=300 で窓数 500、キャンセルで E_CANCELLED
C 映像
- 横 1080p30、縦 1080×1920（display matrix 回転 → 表示寸法のみ反映、出力に回転メタデータなし）、720p/25fps/mono、29.97、50、59.94、60fps、VFR（検出・警告）、
  負 PTS/edit list（discard パケット除外、T0 = 最初の表示フレーム、N=345）、音声 +200ms / 音声先行 150ms、末尾短い音声、HEVC 8bit（警告付き受理）
- 拒否: 音声なし E_NO_AUDIO、HDR(PQ) E_FORMAT、10bit E_FORMAT、インターレース E_FORMAT、4K E_TOO_BIG_FRAME、MKV E_FORMAT、VP9 E_FORMAT、破損 E_FORMAT、6ch 音声 E_FORMAT
D 出力（dev encoder libx264、filter graph は配布版と同一）
- 削除 0 / 1 / 600（filter script 20KB 超、フレーム数一致）、長さ E/30、フレーム数 = E（ffprobe パケット数）、音声長の差 ≤ 48ms、A/V 終端差 ≤ 50ms、
  画角維持（1920×1080、720×1280、25fps→30fps）、mono 128kbps / stereo 192kbps
- 同期マーカー（白フレーム + ビープ）: 1080p30、25fps、29.97、59.94、50、VFR、音声遅延 +200ms（音声マーカーが映像の 6 フレーム後 = 遅延維持）、
  音声先行 150ms（4.5 フレーム前）で、各地点のズレ ≤ 1 フレーム
- AC03: 元素材の SHA-256 が書き出し前後で同一
- 長い日本語パス/絵文字/引用符/& を含む出力パス: argv で渡し成功
- キャンセル: 'q' 送信 → 5 秒以内に終了、E_CANCELLED、一時ファイルのみ
- read-only 保存先: root 実行のため本ホストでは検証不能（スキップ、Windows で実施）
- つなぎ目試聴: 前後 2 秒（端でクリップ）、元版 170 フレーム / 編集版 120 フレーム、-ss + -copyts、先頭付近はシークなし、検証合格
